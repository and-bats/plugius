# Plugius

Локальний каталог музичних плагінів на твоєму Mac: що встановлено, звідки взялось, коли поставлено й де лежить ліцензія. Нічого не надсилає в інтернет.

[English](README.md)

![Plugius: список плагінів і смуга диска за виробниками](docs/screenshot.png)

*На скріншоті демонстраційні дані.*

## Навіщо

Після кількох років роботи з музикою вже ніхто не пам'ятає, в якому акаунті виробника куплено плагін, чи його ліцензія в iLok, ключем у листі чи файлом десь в `Application Support`, і чому ревербератор 2019 року досі займає гігабайт. Plugius сканує теки з плагінами й пам'ятає це замість тебе.

## Можливості

- **Усі формати:** AU, VST2, VST3, AAX, CLAP, LV2, RTAS, а також Windows `.dll` / `.vst3` і Linux `.so`, що опинились на Mac.
- **Один рядок на продукт:** AU, VST3 і AAX одного плагіна зібрані разом, файли розгортаються одним кліком.
- **Дата встановлення** з журналу пакетів macOS, із запасним варіантом за датою файлу. Дати, старіші за сам Mac, позначаються як «перенесено?».
- **Звідки скачано:** ID пакета, позначка «завантажено з» в інсталятора або схожий інсталятор у `~/Downloads`.
- **Ліцензії:** відомі місця ліцензій за виробниками, ручні записи мають пріоритет.
- **Ручні записи не затираються:** джерело, ліцензія, опис, виробник і нотатки лишаються після кожного скану.
- **Місце на диску за виробниками** і смужка розміру в кожного плагіна.
- **Нові плагіни підсвічуються** після скану, видалені лишаються в списку як «видалені з диска».
- **Штатні плагіни** Logic Pro та Pro Tools сховані, є фільтр «Штатні плагіни програм».
- **Автоскан раз на тиждень** (launchd) і експорт у CSV.
- **Українська й англійська:** мова інтерфейсу береться з macOS, перемкнути можна в налаштуваннях. Твої записи й назви плагінів не перекладаються.
- **Офлайн:** нічого не залишає твій Mac. Застосунок слухає лише `127.0.0.1`.

## Стан

Plugius — молодий особистий проєкт. Він щодня працює на Mac автора, але на інших комп'ютерах його поки майже не перевіряли. Місця ліцензій звірено лише для кількох виробників, решта зібрана з досвіду, і їх можна виправити у файлах правил.

## Встановлення

1. Завантаж `Plugius-app.zip` з [останнього релізу](https://github.com/alanmortus-plug/plugius/releases/latest) (близько 18 МБ). Потрібна macOS 11.3 або новіша, Apple Silicon чи Intel. Більше нічого: застосунок має власний Python.
2. Розпакуй і перетягни `Plugius.app` у Програми. Зроби це до першого запуску, інакше тижневий автоскан не ввімкнеться.
3. Відкрий. Застосунок не нотаризований Apple, тож перше відкриття macOS блокує:
   - macOS 13 і новіші: Системні параметри → Приватність і безпека, унизу «Все одно відкрити» біля повідомлення про Plugius.
   - macOS 12 і старіші: правий клік на `Plugius.app` → Відкрити, і ще раз «Відкрити» у вікні.

   Це потрібно лише один раз.

## Збирання з коду

Потрібні Command Line Tools (`xcode-select --install`). Python для застосунку (близько 50 МБ) завантажується один раз і перевіряється за закріпленими SHA-256.

```bash
git clone https://github.com/alanmortus-plug/plugius.git
cd plugius
python3 tools/fetch_python.py
python3 tools/build_app.py
```

Застосунок буде в `dist/Plugius.app`, архів у `dist/Plugius-app.zip`.

Веб-версія без збирання: `python3 app/pluginvault.py serve`, далі http://127.0.0.1:8765.

## Дані

`~/Library/Application Support/PluginVault/`: база, лог і правила (`stock_rules.json`, `license_rules.json`, `vendor_rules.json`). Правила можна редагувати: оновлення застосунку додає нові типові правила, не затираючи твоїх правок.

«Звідки скачано» та шляхи ліцензій визначаються евристично, решту вписуй вручну.

## Як це працює

Python 3 лише зі стандартною бібліотекою (застосунок несе власний Python 3.13 з [python-build-standalone](https://github.com/astral-sh/python-build-standalone)), SQLite і невеликий локальний вебсервер. Інтерфейс — один HTML-файл, а вікно застосунку — тонка оболонка Swift `WKWebView`. Жодних залежностей і жодного доступу до мережі.

## Як допомогти

Найкорисніше зараз — правила: де лежать ліцензії виробників, якими ти користуєшся, і штатні плагіни інших DAW. Це звичайні JSON-файли в `app/rules/`. Перед тим як надсилати зміну, запусти тести:

```bash
python3 tests/test_all.py
```
